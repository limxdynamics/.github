# .github

This repository provides **organization-wide default community health
files** for [LimX Dynamics](https://www.limxdynamics.com) public
repositories on GitHub. Any repository that doesn't have its own copy of a
file below inherits the version here.

- [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md)
- [CONTRIBUTING.md](./CONTRIBUTING.md)
- [SECURITY.md](./SECURITY.md)
- [SUPPORT.md](./SUPPORT.md)
- [PULL_REQUEST_TEMPLATE.md](./PULL_REQUEST_TEMPLATE.md)

A repository's own file, if present, always takes precedence over the
default here.

# .github

本仓库为 [LimX Dynamics](https://www.limxdynamics.com) 的公开仓库提供**组织级默认社区文件**。任何没有自带对应文件的仓库都会继承这里的版本。

- [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md)（行为准则）
- [CONTRIBUTING.md](./CONTRIBUTING.md)（贡献指南）
- [SECURITY.md](./SECURITY.md)（安全策略）
- [SUPPORT.md](./SUPPORT.md)（支持渠道）
- [PULL_REQUEST_TEMPLATE.md](./PULL_REQUEST_TEMPLATE.md)（PR 模板）

如果某个仓库自带同名文件，以该仓库自己的文件为准，本仓库的默认版本不生效。
