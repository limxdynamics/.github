# Support

This is the **organization-wide default** support guide for LimX Dynamics
open-source repositories.

## Where to get help

- **Documentation** — start with the repository's `README.md` for Quick
  Start and usage instructions. Product-level docs: https://www.limxdynamics.com
- **Bugs and feature requests** — open an issue in the specific repository
  the question or problem relates to. Please search existing issues first.
- **Usage questions / general discussion** — use the repository's
  Discussions tab if enabled, otherwise open an issue.
- **Security vulnerabilities** — do **not** use issues; follow
  [SECURITY.md](https://github.com/limxdynamics/.github/blob/main/SECURITY.md).
- **Business, partnership, or product inquiries** — contact
  **contact@limxdynamics.com**.

## Response expectations

This is community/open-source support on a best-effort basis, not a
guaranteed-SLA commercial support channel. There is no fixed response-time
commitment.

## Before you ask

To help us help you faster, please include:

- Repository name and version/commit you're using.
- Operating system, robot model/firmware (if applicable), and environment.
- Steps to reproduce, expected behavior, and actual behavior.
- Relevant logs or error output (with any secrets/internal info removed).

# 支持与求助

本文件是 LimX Dynamics 开源仓库的**组织级默认支持指南**。

## 在哪里获取帮助

- **文档**：请先查阅对应仓库 `README.md` 中的 Quick Start 与使用说明。产品级文档见 https://www.limxdynamics.com
- **Bug 与功能请求**：请在问题所属的具体仓库中提 Issue，提交前请先搜索是否已有相关 Issue。
- **使用咨询 / 一般讨论**：如仓库开启了 Discussions，请使用该功能；否则可直接提 Issue。
- **安全漏洞**：**请勿**通过 Issue 报告，请参阅
  [SECURITY.md](https://github.com/limxdynamics/.github/blob/main/SECURITY.md)。
- **商务合作 / 产品咨询**：请联系 **contact@limxdynamics.com**。

## 响应说明

本支持渠道为开源社区支持，尽力而为，并非承诺 SLA 的商用支持通道，不设固定响应时限。

## 提问前请准备好

为了让我们能更快帮到你，请附上：

- 仓库名称及你所使用的版本 / commit。
- 操作系统、机器人型号 / 固件版本（如适用）及运行环境。
- 复现步骤、预期行为与实际行为。
- 相关日志或报错信息（请先移除密钥 / 内部信息）。
